# GEISHA

GEISHA is an interactive terminal workbench for exploring, plotting and fitting optical interferometry data with PMOIRED.

## Installation

Requires Python 3.12 or 3.13.

```bash
git clone https://github.com/AlessioPop/GEISHA.git
cd GEISHA
python3.12 -m venv .venv
source .venv/bin/activate
pip install .
geisha
```

Use `python3.13` instead of `python3.12` if that is your installed version.
